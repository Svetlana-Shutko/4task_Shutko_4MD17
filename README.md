# Еловый мыс — бронирование загородных домов

Учебный сайт для практического задания 4 «Интерактивная карта и живой интерфейс бронирования».

**Тема:** загородные дома. Вымышленный посёлок «Еловый мыс» у озера Светлое: 8 домиков на собственной схеме (дорога, лес, озеро, причал). Пользователь выбирает домик, указывает число гостей и ночей, видит стоимость и оформляет учебную бронь. В разделе «Мои брони» запись можно отменить.

> Учебное демо: бронирования сохраняются только в этом браузере. Реальная бронь и оплата не оформляются.

## Функции

- **Схема и список** строятся из одного массива `HOUSES` (`js/data.js`). Выбор в списке подсвечивает домик на схеме и наоборот.
- **Статусы не только цветом:** у каждого домика есть подпись (Свободен / Выбран / Занят / Ваша бронь), значок (✓, ✕, ★) и разная обводка (у занятых — пунктир и штриховка). Есть легенда.
- **Занятый домик выбрать нельзя:** при нажатии появляется сообщение. Два домика («Рыбацкая» и «Семейная») заняты изначально.
- **Фильтры:** число гостей, максимальная цена за ночь, «только свободные» и кнопка сброса. Схема и список фильтруются одинаково. Показывается счётчик «Показано N из 8». Если фильтр скрыл выбранный домик, выбор сбрасывается с сообщением. При пустом результате показывается подсказка.
- **Карточка домика:** описание, вместимость, цена, удобства.
- **Форма:** гостей от 1 до вместимости, ночей от 1 до 30, только целые числа. Ошибки показываются рядом с полем. Сумма `цена за ночь × ночи` пересчитывается при вводе.
- **Подтверждение** создаёт одну бронь с номером (ЕМ-0001…). Двойной клик не создаёт дубликат. Без выбранного домика показывается ошибка.
- **Мои брони:** номер, домик, гости, ночи, сумма, дата. Отмена в два нажатия («Отменить бронь» → «Точно отменить?») освобождает домик на схеме и в списке.
- **Сохранение** в `localStorage` под одним ключом `elovyi-mys:bookings:v1`, весь `localStorage` не очищается. Повреждённые данные или запрет хранения выводят понятное сообщение, страница не ломается. Кнопка «Сбросить демо» тоже срабатывает со второго нажатия.
- **Адаптивность и доступность:** на компьютере схема и карточка стоят рядом, на телефоне друг под другом. Все домики — кнопки, их можно выбрать с клавиатуры (Tab, Enter). Фокус виден, у полей есть подписи. Есть светлая и тёмная тема (по настройке системы).

## Запуск

Стек: HTML, CSS и ванильный JavaScript (ES-модули). Без сборки, npm и сервера.

ES-модули не работают при открытии файла двойным щелчком (`file://`), поэтому нужен любой локальный сервер:

- VS Code → расширение **Live Server** → «Open with Live Server», или
- в папке проекта: `python -m http.server 8000`, затем открыть http://localhost:8000

### Публикация на GitHub Pages

1. Загрузите файлы в репозиторий (структура ниже должна лежать в корне).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html        разметка страницы
css/style.css     оформление, светлая и тёмная тема, адаптивность
js/data.js        данные домиков (id, название, описание, вместимость, цена, координаты, занятость)
js/storage.js     чтение и запись броней в localStorage
js/app.js         схема, фильтры, выбор, форма, расчёт, брони и отмена
```

## Как проверить

1. Нажать «Подтвердить бронь» без выбора — ошибка «Сначала выберите свободный домик».
2. Нажать на занятый домик (№ 3 или № 6) — сообщение, выбор не происходит.
3. Выбрать «Сосновую», ввести 5 гостей — ошибка (вместимость 4). Ввести 2,5 ночи — ошибка.
4. Ввести 3 гостя и 3 ночи — сумма 15 600 ₽. Дважды быстро нажать «Подтвердить» — появится одна бронь.
5. Обновить страницу — бронь на месте, домик отмечен «Ваша бронь».
6. Фильтр «от 8 гостей» + цена до 5 000 ₽ — пустой результат с подсказкой.
7. Отменить бронь — домик снова свободен.
8. Открыть сайт на телефоне и пройти тот же путь.

## Ограничения

Это учебное бронирование: нет сервера, оплаты и регистрации. Брони хранятся только в текущем браузере и не видны другим людям. Дом бронируется целиком до отмены, без календаря дат.
